<h1 align="center">swimUI</h1>

<p align="center">Une interface en verre pour Windows 11 : barre de menus, dock, recherche, centre de contrôle, notifications et widgets.</p>

<p align="center"><a href="https://github.com/JOHANITO203/swimUI-telechargement/releases/latest/download/swimUI-Installation.exe"><b>Télécharger swimUI pour Windows 11</b></a> · 222 Mo</p>

## Ce que swimUI ajoute à Windows

- **Une barre de menus** en haut de l'écran, avec les menus de l'app active, la batterie, le wifi, la recherche et l'heure.
- **Un dock** qui grossit sous le pointeur, avec des pastilles de notifications, une corbeille qui se remplit et le glisser-déposer de fichiers.
- **Une recherche** pour ouvrir une app, un réglage ou un document au clavier (Alt + Espace).
- **La vue d'ensemble** de toutes vos fenêtres, des coins actifs, et le placement des fenêtres en moitiés de l'écran.
- **Des widgets** sur le bureau : horloge, calendrier, météo, batterie, musique, système.

swimUI est une application native. Au repos, elle n'utilise pas le processeur et occupe environ 190 Mo de mémoire.

## Installer

1. Téléchargez `swimUI-Installation.exe`.
2. Lancez-le et suivez l'assistant. Aucun droit administrateur n'est demandé, et rien d'autre n'est à installer.

Windows peut afficher « Windows a protégé votre ordinateur », car l'installable n'est pas encore signé. Cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.

## Désinstaller

Ouvrez **Paramètres > Applications installées**, cherchez swimUI, puis choisissez **Désinstaller**. La barre des tâches de Windows revient telle que vous l'aviez.

## Configuration requise

Windows 11, processeur 64 bits.
